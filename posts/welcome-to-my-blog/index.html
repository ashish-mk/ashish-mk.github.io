A Quick Code Example

Here is a quick Python snippet illustrating the clean, minimalist styling supported right out of the box:

from dataclasses import dataclass
from typing import List

@dataclass
class MarketSignal:
    timestamp: str
    commodity: str
    forecast_delta: float

def filter_signals(signals: List[MarketSignal], threshold: float = 0.05) -> List[MarketSignal]:
    """Filters market signals exceeding an alpha significance threshold."""
    return [s for s in signals if abs(s.forecast_delta) >= threshold]
